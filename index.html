04 / Гайд

Установка за 3 минуты

  1. 1

    Установи Fabric Loader

    Скачай Fabric Loader для Minecraft 1.21.11 и запусти установщик. Выбери свою версию игры.

  2. 2

    Положи Fabric API

    Закинь Fabric API в папку .minecraft/mods. Без него клиент не запустится.

  3. 3

    Положи CrystalVisuals

    Скинь .jar клиента в ту же папку mods и запусти Fabric-профиль.

  4. 4

    Готово

    Открой меню клавишей R (по умолчанию) и включай модули.
