Статика, без сборки и зависимостей. Три файла в корне репозитория.

## Файлы

```

main.js         логика

shot-3.png      скриншот: модули в игре
.nojekyll       для GitHub Pages
```

## Заливка

1. `Add file → Upload files` — перетащи всё в корень
2. `Commit changes`
3. `Settings → Pages` → `Deploy from a branch` → `main` → `/ (root)` → `Save`

## Если сайт выглядит без стилей

Значит `style.css` побился при копировании. **Не копируй CSS через веб-редактор GitHub.**

Надёжный способ:
```bash
git clone https://github.com/webworld11121/CrystalVisuals.git
cd CrystalVisuals
# скопируй файлы сюда обычным перетаскиванием
git add .
git commit -m "site"
git push
```

Или в редакторе с автоформатированием (VS Code, Sublime) — они не ломают структуру.

## GUI на сайте

Кнопка **ОТКРЫТЬ GUI** в hero и плавающая кнопка справа снизу открывают
полноценное меню — то же, что в клиенте.

| Действие | Что делает |
|---|---|
| ЛКМ по модулю | вкл / выкл |
| ПКМ | попап настроек |
| СКМ | назначить бинд, затем нажми клавишу |
| Esc в окне бинда | снять бинд |
| Ctrl + колесо | зум панели |
| перетаскивание за верхнюю полосу | двигать панель |
| двойной клик по названию категории | сбросить категорию |

Состояние модулей и бинды сохраняются в `localStorage`.

## Поиск

Работает по русской раскладке — из кода клиента, `layoutNormalize()`.
Ввёл `с` — найдёт `Crosshair`. Ввёл `прицел` — тоже найдёт.

## Цифры

Счётчики взяты с реального скриншота GUI: **41 / 15 / 26 = 82**.

Массив `M` в `main.js` содержит 83 записи. Разница в том, что в клиенте
`CustomPet` и `Customization` включаются напрямую через `.enable()`
и в список модулей не попадают. Если счётчики в живом клиенте
другие — поправь массив и числа в `index.html`.
